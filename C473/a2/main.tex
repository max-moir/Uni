\section{Design Decision}


If I were to do the project again, one design decision I would've made early on would be unifying the message datatype.
In my implementation, there is not one single source of truth for what a message should contain, with different datatypes for the database, swarm, frontend and bridge api.
In addition to this, I decided to first interface between the frontend and the server, then between the server and the swarm_runner.
This is honestly a pointless distiction, and made my life much harder while developing this, because I had to redefine commands in 3+ places.
